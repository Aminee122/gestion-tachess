# Gestion des taches (Python)

Application console simple pour gerer des taches quotidiennes.
Projet de Licence 1 - Outils collaboratifs (Git / GitHub).

## Fonctionnalites
- Ajouter une tache (titre vide refuse)
- Afficher toutes les taches numerotees
- Rechercher une tache par mot-cle
- Quitter le programme (toute autre option affiche une erreur)

## Etapes realisees
1. Creation du programme `main.py` (menu, ajout, affichage)
2. Ajout du `README.md`
3. Ajout de la recherche de taches
4. Amelioration : message si la recherche ne trouve rien

## Execution
1. Ouvrir le dossier du projet dans VS Code
2. Ouvrir `main.py`
3. Cliquer sur le bouton **Run Python File** (triangle en haut a droite)
